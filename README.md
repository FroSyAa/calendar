# Календарь доступности

Недельный календарь свободных часов. Vue 3 + TypeScript + Vite, без календарных UI-библиотек.

## Возможности

- Слоты ПН–ПТ, 10:00–19:00: клик отмечает час, повторный клик снимает отметку.
- Выбор диапазона: первый клик задаёт начало, второй — конец, весь диапазон отмечается или снимается целиком.
- Прошедшие часы текущего дня заблокированы.
- Данные каждой недели хранятся в localStorage отдельно и переживают перезагрузку страницы.
- Итоги: свободные часы по каждому дню и за неделю, очистка недели с подтверждением.
- Локализация ru/en и тёмная/светлая тема с сохранением выбора.
- Адаптив: на десктопе календарь виден целиком, на планшете скроллится по горизонтали, на телефоне дни листаются вертикально, а навигация закреплена снизу экрана.

Если нет -- то искать на каком порте запустился сайт в логах терминала.

## Стек

- Vue 3 (Composition API, `<script setup>`), TypeScript, Vite
- vue-i18n (ru/en), тёмная/светлая тема
- SCSS: собственные хелперы (media-миксины, функции, миксины), без UI-библиотек календаря

## Хранение данных

- Отметки каждой недели: ключ localStorage `availability_<дата понедельника>`.
- Выбранная тема: ключ `availability_theme`.
